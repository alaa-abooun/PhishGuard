AI Email Generation Module

Powered by
local LLaMA 3.2

🔄  Generation Flow
Admin sets topic, tone, urgency, difficulty
Backend builds a structured prompt with safety guardrails
Ollama generates 3–5 email variations locally
Safety check runs before any output is saved
Admin reviews, edits, approves one email
Fallback templates used if Ollama is offline
📝  What AI produces
Realistic subject lines with urgency triggers
Sender impersonation — IT, HR, management
Embedded red flags referenced in the training page
Fake login page that never stores real credentials
Prompt logs saved per campaign for audit
100% local — no data sent to external APIs
